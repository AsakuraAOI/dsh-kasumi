# Kasumi 适配 __VERSION__

可安装的 DeepSeek Harness Cordis Bundle，提供自动纯文本压缩、工具输出预算和读取批次保护。保留当前模式的角色、技能、工具和权限。

## 安装分享包

在 DSH 插件管理器选择本地目录或 .tgz 文件，按结果提示重启。此过程无需 npm install 或源码构建。

接收者需自行配置模型通道与凭据。在全局适配的 `providers` 列表中核对实际模型通道 ID；凭据引用、预设内部标识和开发参数以包内代码配置为准。

## 使用

在「插件 → Kasumi 适配 → 组件」启用或禁用全局适配。默认每步最多 8 次文本读取；大工具输出会提供缩减预览和完整格式化文本的回读路径。技能正文、图片与结构化值保留。

可以继续使用原版模式，也可以选择 Kasumi 轻量版、均衡版、创造模式。另装 StudyMate 后可使用学习模式。

总开关与分项参数通过原生实时配置调整。关闭全局层后恢复所选模式自身的行为；`/compact` 继续使用原模式后端。分享包不包含本机实验用的精确请求编译预检通道。

## 卸载与分发

通过插件管理器移除本 Bundle，其他插件和学习数据保留。分享文件不包含模型服务、API Key、DSH 运行时或完整 StudyMate；接收者使用自己的环境。

第三方来源与许可见包内 `THIRD_PARTY_NOTICES.md`。本包保留 `private: true` 以阻止误发 npm，可以通过本地文件分发。
