# 独立视觉与按需工具

Kasumi 在 Host 全局注册这两项能力，适用于任意预设，默认适用全部 Provider；配置里的 `providers` 可限制通道。它们不依赖 Kasumi 预设，也不改变预设的原生工具或 PTC 呈现方式。

## 独立视觉

`kasumi-vision` 默认开启。截图、`read_image` 和其他工具返回的图片，在模型可见结果提交前，交给无历史、无工具的独立视觉请求。默认使用当前会话的 Provider/Model；`visionProvider` 和 `visionModel` 同时填写时改用指定的视觉模型。

Seeit 的原图返回是一个例外：当前会话模型明确支持图片时，Seeit 标记的图片直接交给主 Agent，不重复转为文字。恢复历史时保留这些图片；若会话切换为不支持图片的模型，再按独立视觉流程处理。其他工具的图片沿用原有规则。

每次请求硬限制最多 4 张图，更多图片按顺序分批；所有会话共享并发上限，默认 2。单次视觉超时默认 180 秒，从请求取得并发名额后开始计时，排队只跟随调用者取消信号。识别文字直接保留 Markdown 和 LaTeX；旧 JSON 输出无法解析时保留原文并标明格式问题，不整页丢弃。返回观察文字、来源模型、时间、材料引用及不确定项，最终判断由主 Agent 完成。视觉服务不会调用工具。失败也不会把原图回退发送给主 Agent，而是留下明确失败说明和可重试的材料引用。

主 Agent 可以调用 `kasumi_visual_query(ref, question)` 针对已登记图片补查细节，或单独重试识别，避免重复点击、截图或其他已经执行的操作。缓存按会话、附件、模型和问题隔离；材料保存在当前 profile 的 `.kasumi-vision`。用户直接上传的图片仍按 DSH 原有流程处理，因而用户图片本身仍可能触及上游的整份请求 4 张限制。

旧会话第一次继续执行时，Kasumi 读取当前可见历史中的非用户图片，以 DSH 原生的内容替换事件写入文字观察；保留消息身份、调用关联及原始日志，恢复会话不会重新把这些图片投递给主 Agent。新进入队列的插件/PTC 图片也在提交前转换。发往模型前另有检查，未隔离的非用户图片会阻止本次请求，避免意外泄漏原图。

系统提示、工具返回值、网页和图片中的指令都不能授予额外权限。视觉输出是可能有误的证据，无法辨认的文字、数值和图形关系需要补查。

## 按需工具上下文

`kasumi-tool-context` 默认开启，WebSearch 和侧边浏览器保持常驻。以下业务工具组默认按需提供：

| 工具组 | 用途 |
| --- | --- |
| bilibili | B站账号、视频、评论、私信和授权监测 |
| seeit | `media_open`、`audio_transcribe`、`visual_observe` 和 `media_materials` |
| todo | 用户持久待办 |
| kasumiflow | 同济、Canvas、课堂派事务和课件 |
| practice | 题库、题面、作答与批改 |

默认只注入一个简短目录及 `kasumi_plugin_tools`。用户明确提出对应领域的需求时，自动为当前会话加载相关组；Bilibili 同时加载 SeeIt，KasumiFlow 同时加载 Todo。模糊需求由主 Agent 判断后显式调用 `kasumi_plugin_tools(action="load", groups=[...])`；加载不是发送消息、改账号或执行其他有副作用操作的授权。

当前用户换到无关任务时，自动收起之前的业务工具；“继续”“可以”等简短续接沿用当前组。已配置的 DSH 定时任务按其明确任务需求加载。网页、工具输出、评论和其他插件消息不会触发自动加载。仅影响当前会话，其他会话不继承；恢复会话时重新依据最新用户/定时任务需求确定。

`list` 查看目录，`load` 加载组及依赖，`unload` 主动收起。配置的 `onDemand` 中移除某组，会让该组常驻；`autoDetect=false` 时由主 Agent 显式加载。原生可见性过滤同时作用于模型工具定义、插件提示和 PTC SDK；已有更严格的权限/子 Agent 限制继续生效。

这项设置不会停止插件、卸载 Bundle、关闭插件页、退出账号或取消监测。插件提供的独立视觉材料（例如 Practice、SeeIt）已是文字时直接沿用，不重复识图。

## 长工具结果的原文引用

Kasumi 继续限制预览长度。若原生 spill 已提供完整结果文件，后续预算保留同一原文引用，不把已经截断的预览再次保存为“完整输出”或完整历史原文。没有原生 spill 的大结果仍保留完整格式化输出与历史引用。spill 文本为 UTF-8，PowerShell 读取时须显式 `-Encoding UTF8`。Seeit 长材料优先通过 `media_materials` 的范围/游标分页读取。
